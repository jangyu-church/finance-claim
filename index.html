    사용 방법

    1. 영수증 촬영 — 여러 장이면 계속 찍으세요. 장마다 금액이 자동 인식됩니다.

    3. 영수증이 없을 때 — ‘직접 입력’으로 금액과 사유를 적습니다.
    4. 청구하기 — 합계 금액으로 재정부에 바로 접수됩니다.
