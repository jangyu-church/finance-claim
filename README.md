# 장유중앙교회 재정청구 앱

영수증을 사진으로 찍으면 **금액이 자동으로 인식**되어 청구서에 들어가고, 영수증 사진은 자동으로 첨부되는 휴대폰 앱입니다.

- 📷 **영수증 여러 장 촬영** → 장마다 금액 자동 인식 → **합계 자동 계산**
- ✍️ **영수증이 없을 때** → 금액과 사유를 직접 입력
- 📲 첫 화면의 **[바탕화면에 설치하기]** 버튼으로 휴대폰에 앱처럼 설치
- 📊 접수된 청구는 **구글 시트**에 자동 기록, 영수증은 **구글 드라이브** 폴더에 자동 보관
- 🖨 재정부는 시트의 **[청구서 보기]** 링크로 결재란이 있는 지출청구서를 인쇄/PDF 저장
- 🗂 **재정부 관리 앱**(`/admin/`) — 휴대폰으로 청구 확인 · 영수증 확대 · 승인/반려 · 지급완료 · 월별 통계

## 구조

| 구성 | 역할 |
|---|---|
| **GitHub Pages** (`index.html`, `app.js` …) | 교인들이 쓰는 청구 앱 (설치형 웹앱, PWA) |
| **GitHub Pages** (`admin/`) | 재정부 관리 앱 (따로 설치되는 별도 앱) |
| **Google Apps Script** (`apps-script/Code.gs`) | 서버: 영수증 글자 인식(OCR), 시트 기록, 드라이브 보관 |
| **Google 시트** | `청구서` · `청구내역` · `설정` · `처리기록` 시트 |

## 설치 순서 (재정부 관리자용, 약 15분)

### 1단계 — 구글 시트와 Apps Script 준비

1. 교회 재정부 구글 계정으로 [새 구글 시트](https://sheets.new)를 만들고 이름을 `재정청구`로 정합니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기본으로 있는 `Code.gs` 내용을 모두 지우고, 이 저장소의 **`apps-script/Code.gs`** 내용을 붙여 넣습니다.
4. 왼쪽 **서비스 ＋** → **Drive API** 선택 → **추가** (영수증 글자 인식에 필요)
5. 💾 저장 후, 시트로 돌아와 **새로고침**하면 상단에 **💰 재정청구** 메뉴가 생깁니다.
6. **💰 재정청구 → ① 초기 설정** 을 누릅니다.
   - 처음에는 "권한 승인" 창이 뜹니다 → 계정 선택 → **고급 → (안전하지 않음)으로 이동 → 허용**
   - **교회 접근 코드**(예: `0691`)를 정합니다. 교인들은 이 코드로만 청구할 수 있습니다.
   - 이어서 **재정부 관리자 코드**를 정합니다. 계좌번호 등 개인정보를 볼 수 있으니 **교인용 코드와 다르게, 8자 이상**으로 정하고 재정부원에게만 알려 주세요.

### 2단계 — 웹 앱으로 배포

1. Apps Script 편집기 오른쪽 위 **배포 → 새 배포**
2. 유형 선택(⚙) → **웹 앱**
3. **실행 계정: 나** / **액세스 권한이 있는 사용자: 모든 사용자** → **배포**
4. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> 코드를 고친 뒤에는 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포**를 해야 반영됩니다. (주소는 그대로 유지)

### 3단계 — GitHub에 올리고 앱 주소 만들기

1. [github.com](https://github.com) 로그인 → **New repository** → 이름 `finance-claim` → **Public** → Create
2. **uploading an existing file** 을 눌러 이 폴더의 파일을 모두 끌어다 놓고 **Commit changes**
   (`apps-script` 폴더, `icons` 폴더 포함)
3. 저장소에서 **`config.js`** 를 열고 ✏️ 연필 버튼 → `API_URL: ''` 따옴표 안에 2단계의 웹 앱 URL을 붙여 넣고 저장
4. **Settings → Pages** → Branch: **main** / **/(root)** → Save
5. 1~2분 뒤 `https://<GitHub아이디>.github.io/finance-claim/` 주소가 생깁니다. 이 주소가 **앱 주소**입니다.

### 4단계 — 교인들에게 안내

카카오톡 공지 예시:

> 📲 재정청구가 앱으로 바뀌었습니다!
> ① 아래 주소를 **크롬(아이폰은 사파리)** 으로 여세요: https://…github.io/finance-claim/
> ② 접근 코드 `0691` 입력
> ③ **[📲 설치]** 버튼 → 바탕화면에 아이콘이 생깁니다.
> 이제 영수증만 찍으면 청구 끝!

※ 카카오톡 안에서 열면 설치가 안 됩니다. 앱이 '크롬으로 열기' 안내를 띄워 줍니다.

## 재정부 관리 앱

주소: `https://<GitHub아이디>.github.io/finance-claim/admin/` → 관리자 코드와 **처리자 이름**으로 로그인 → **[📲 설치]**
(교인용 앱과 아이콘·이름이 다른 별도 앱으로 설치됩니다.)

| 화면 | 할 수 있는 일 |
|---|---|
| **청구 관리** | 처리 대기 / 지급 예정 / 이번 달 지급 합계를 한눈에. 대기·승인·지급완료·반려 탭, 이름·부서 검색. 새 청구에는 `NEW` 표시 |
| **청구 상세** | 입금 계좌 **[계좌 복사]**(이체 앱에 바로 붙여넣기), 전화 걸기, 항목별 영수증 사진(눌러서 크게 보기). 자동인식 금액을 고친 항목과 영수증 없는 항목은 **주황색으로 경고** |
| **처리 버튼** | 검토 시작 → **승인** → **지급완료** / **반려**(사유 필수, 청구자 앱에 표시). 실수했을 때 ‘승인 취소’, ‘지급 취소’, ‘다시 접수’ 가능 |
| **여러 건 선택** | 대기 탭에서 **일괄 승인**, 승인 탭에서 선택 합계를 보며 **일괄 지급완료** |
| **월별 통계** | 월별 청구 합계·지급 완료·미처리, **부서별 / 계정과목별** 막대그래프 |

모든 처리는 `처리기록` 시트에 **누가, 언제, 어떤 상태에서 어떤 상태로** 바꿨는지 자동 기록됩니다. (재정 감사 대비)
관리자 코드를 10분 안에 20번 넘게 틀리면 잠시 잠깁니다.

## 재정부 업무 흐름 (시트에서 직접 할 때)

1. 청구가 들어오면 `청구서` 시트에 한 줄이 추가됩니다. (`설정` 시트에 **알림이메일**을 적으면 메일도 옵니다)
2. **청구서 보기** → 결재란이 있는 지출청구서 + 영수증 사진 → 인쇄 또는 PDF 저장
3. (관리 앱 대신 시트에서 처리할 때) **상태** 칸을 `검토중 → 승인 → 지급완료` (또는 `반려`)로 바꿉니다.
   청구자는 앱의 **상태 새로고침**으로 진행 상황을 봅니다. `재정부 메모` 칸에 적은 내용(반려 사유 등)도 함께 보입니다.
4. `청구내역` 시트에는 영수증 1장 = 1줄로 기록됩니다. 자동인식 금액과 다르게 고친 경우 **‘수정함’** 표시가 붙어 검토에 도움이 됩니다.

## 설정 바꾸기

- **부서·계정과목**: `설정` 시트 A열·B열을 고치면 앱에 바로 반영됩니다.
- **접근 코드 변경**: 💰 재정청구 → 접근 코드 변경 (교인용) / 관리자 코드 변경 (재정부용)
- **임시 파일 정리(선택)**: 인식만 하고 제출하지 않은 사진은 `재정청구_영수증/_임시(인식중)` 폴더에 남습니다.
  Apps Script **트리거(⏰) → 트리거 추가 → `cleanupTempFiles` / 시간 기반 / 주 단위**로 설정하면 30일 지난 파일을 자동 삭제합니다.

## 알아 두실 점

- 금액 인식은 구글 드라이브의 글자 인식(OCR)을 사용합니다. 구겨지거나 흐린 영수증은 틀릴 수 있으므로, **인식 후 금액 확인**을 꼭 안내해 주세요. 후보 금액이 여러 개면 버튼으로 골라 넣을 수 있습니다.
- 앱 주소는 공개되지만, **접근 코드 없이는 청구·조회가 불가능**합니다. 영수증과 시트는 재정부 계정의 드라이브에만 저장됩니다.
- 사진은 휴대폰에서 자동으로 줄여서(약 2000px) 보내므로 데이터가 많이 들지 않습니다.
